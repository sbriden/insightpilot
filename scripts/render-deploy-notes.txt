InsightPilot — Render deploy checklist
======================================

1. Push this branch to GitHub.
2. In Render: New → Blueprint → select the repo (uses render.yaml).
3. Before / during first deploy, set these Blueprint env values:
   - insightpilot-api / CORS_ORIGINS
       = https://<your-web-service>.onrender.com
         (exact web origin). Code also allows https://*.onrender.com
         via regex, but set this explicitly anyway.
   - insightpilot-web / NEXT_PUBLIC_API_URL
       = https://<your-api-service>.onrender.com
         (API service URL — NOT the frontend URL.
          Must be set before the web image build — baked into the bundle.)
   - insightpilot-web / API_URL
       = same API origin (runtime). Used by /api/admin/session and
         /api-proxy/* (browser traffic is same-origin via the proxy).
         Do NOT append /api to this value.
   - insightpilot-web / NEXT_PUBLIC_PRIMARY_HOSTS
       = <your-web-service>.onrender.com
         (hostname only, no https://). Missing this used to rewrite
         every page to the published-app loader ("Not found").
         Code now treats *.onrender.com as primary by default.
   - ADMIN_PASSWORD on BOTH api and web (same value)
   - NEXT_PUBLIC_REQUIRE_ADMIN_AUTH is already "1" in render.yaml
4. After deploy, open the web URL → /login → studio.
5. Seed / refresh data:
   Free tier is 512MB — set INSIGHTPILOT_LOW_MEMORY=1 on the API
   (skips PBP-heavy facts, current season only). Do NOT run
   historical on free; upgrade RAM for full loads.
   UI Refresh: run NFL incremental, wait until finished, then CFB,
   then odds — one job at a time.
   Progress: GET /api/sources/nflverse/ingestion-status
             GET /api/sources/sportsdataverse/ingestion-status
6. Published apps:
   - Studio → Publish → set slug → Publish
   - Public path: https://<web>/p/<slug>
   - Optional custom domain: add domain on the web service in Render,
     CNAME to the Render hostname, set custom_domain in Publish panel.

Railway: same Dockerfiles/env vars; swap hosts when signups reopen.
